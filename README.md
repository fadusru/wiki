# Как принять участие в развитии ВиКи (wiki.fadus.ru)?

Всем, кто хочет участвовать в развитии ВиКи - Welcome!

ВиКи работает на движке DokuWiki. Ознакомиться с синтаксисом можно на 
[www.dokuwiki.org/ru:wiki:syntax](https://www.dokuwiki.org/ru:wiki:syntax "Локализация синтаксиса для русского языка") .

В моменте предусмотрены 2 варианта внесения изменений в ВиКи:
* написать новую статью или внести правки в опубликованные статьи на 
[dev.fadus.ru](https://dev.fadus.ru "Копия ВиКи для редактирования / написания новых текстов").
* сделать себе копию (fork) версии ВиКи из репозитория на GitHub. Внести свои правки в тексты 
либо написать новые тексты и отправить запрос на слияние (pull requests) в основной репозиторий.

Давайте детальнее разберемся как это сделать.

## Написание новой статьи или правка опубликованных на dev.fadus.ru

Для удобства разработки новых статей и внесение правок в опубликованные материалы, была развернута копия ВиКи 
на ресурсе [dev.fadus.ru](https://dev.fadus.ru "Копия ВиКи для редактирования / написания новых текстов").

Важно отметить, что ежедневно, в период **с 09:00 до 10:00 МСК выполняется обновление содержимого ВиКи 
([dev.fadus.ru](https://dev.fadus.ru "Копия ВиКи для редактирования / написания новых текстов")) 
из источника ([wiki.fadus.ru](https://wiki.fadus.ru "Источник данных для ежедневной копии"))**.

Из этого вытекают ограничения проекта, ***что после написания новых текстов и/или редактирования уже написанных 
текстов на [dev.fadus.ru](https://dev.fadus.ru "Копия ВиКи для редактирования / написания новых текстов"), 
тексты и media-файлы необходимо сохранить себе на локальный диск или какой-то свой ресурс***.

Для публикации своей редакции материалов и новых публикаций на 
[wiki.fadus.ru](https://wiki.fadus.ru "ВиКи канала FadusRu"), просьба текстовые и media-файлы отправлять 
в чат [@fadusru](https://t.me/fadusru "Telegram канал @fadusru").

## Запрос на слияние на GitHub

Текст и медиа материалы ВиКи публикуются на GitHub: 
[github.com/fadusru/wiki](https://github.com/fadusru/wiki 
"На GitHub хранится копия текстов и media-контента ВиКи wiki.fadus.ru")

Публикацию новых материалов или изменения в уже опубликованных можно выполнить через 
[запрос на слияние (pull requests)](https://github.com/fadusru/wiki/pulls "fadusru/wiki/pulls").
