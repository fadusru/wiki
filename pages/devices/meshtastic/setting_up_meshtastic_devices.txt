====== Настройка устройств Meshtastic ======

В перспективе планирую описать выполнение различных настроек для устройств Meshtastic.

И так, поехали!

  * [[devices:meshtastic:firmware:index|Прошивка устройства]]
===== Настройка ноды =====

Для эффективной работы сети Meshtastic предлагаем выполнить следующие настройки:
  * [[devices:meshtastic:settings:geolocation|настройку геопозиции, в общем случае ставим 4 часа, детали по ссылке]];
  * [[devices:meshtastic:settings:geolocation#я_с_вами_согласен_как_настроить_передачу_геопозиции_на_ноде|отключаем передачу "умной позиции"]]
  * [[devices:meshtastic:settings:geolocation#я_с_вами_согласен_как_настроить_передачу_геопозиции_на_ноде|устанавливаем "фиксированное положение"]]
  * [[devices:meshtastic:settings:telemetry|выключаем передачу телеметрии]]
  * настраиваем 5 хопов
  * для комнатных нод устанавливаем роль устройства client_mute
  * обновляем ноду до последней стабильной прошивки

===== Каналы =====

Для общения в группах настроено несколько публичных каналов:
  * [[#primary_channel|Primary Channel]];
  * [[#NoPings|NoPings]].

==== Primary Channel ====
Канал создается по умолчанию при настройке ноды.

Предлагаем более оптимально настроить канал, без отправки избыточной информации в эфир.

Для этого в настройках канала **Primary Channel** устанавливаем:
  * поле "**Name**" оставляем **пустым**;
  * поле "**Key Size**" оставляем "**Default**";
  * поле "**Key**" должно быть заполнено значением "**AQ==**";
  * поле "**Channel Role**" устанавливаем в "**Primary**";
  * переключатель "**Position Enabled**" переводим в **выключенное состояние**;
  * MQTT. переключатель "**Uplink Enabled**" переводим в **выключенное состояние**;
  * MQTT. переключатель "**Downlink Enabled**" переводим в **выключенное состояние**;

К каналу "Primary Channel", для проверки связности между нодами, подключены боты. 
Боты направляют автоответы на типовые запросы:
  * ping;
  * будет позже детализировано.

==== NoPings ====

Энтузиастами сообщества предложено создание канала без подключенных ботов.

Для настройки канала **NoPings** устанавливаем:
  * поле "**Name**" заполняем значение "**NoPings**";
  * в поле "**Key Size**" выбираем вариант "**1 byte**";
  * поле "**Key**" заполняем значением "**SA==**";
  * поле "**Channel Role**" устанавливаем в "**Secondary**";
  * переключатель "**Allow Position Requests**" переводим в **выключенное состояние**;
  * MQTT. переключатель "**Uplink Enabled**" переводим в **выключенное состояние**;
  * MQTT. переключатель "**Downlink Enabled**" переводим в **выключенное состояние**;
