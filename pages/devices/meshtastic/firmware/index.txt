====== Прошивка устройства ======

===== Подготовка устройства =====

  * Для подключения устройства к ПК необходимо подобрать подходящий для задачи кабель. В продаже присутствуют кабели как для зарядки устройств (2 провода внутри), так и для обмена данными (4 провода внутри). У самого несколько раз попадались провода для зарядки, при подключении к ПК устройство не определялось. Как правило, кабель потолще содержит проводники для передачи данных. Проверить кабель можно, попробовав скопировать файл на смартфон. Если файл передается, кабель подходит.
  * Обязательно подключите антенну к модулю перед подачей питания или подключением к ПК. Работа без антенны может повредить радиочип.

===== Подключение к ПК =====
==== Windows ====
  - Откройте диспетчер устройств, вкладку "**Порты (COM или LPT)**" и посмотрите какие порты есть в системе сейчас.
  - Подключите модуль к компьютеру. Если система не распознала устройство, может потребоваться установить драйвер для [[https://www.silabs.com/software-and-tools/usb-to-uart-bridge-vcp-drivers?tab=downloads|CP210X USB to UART Bridge]] с сайта Silicon Labs.
  - Если устройство распознано, во вкладке портов появится новый COM-порт. Запомните (запишите) его номер. Он понадобится при прошивке устройства.

Инструкция от Microsoft: [[https://support.microsoft.com/ru-ru/windows/обновление-драйверов-с-помощью-диспетчер-устройств-в-windows-ec62f46c-ff14-c91d-eead-d7126dc1f7b6|Обновление драйверов с помощью диспетчер устройств в Windows]]

===== Прошивка через официальный web-флешер =====

==== Установка/обновление прошивки устройств Lora на базе ESP ====
  - Для прошивки устройства в браузере необходимо открыть сайт [[https://flasher.meshtastic.org|flasher.meshtastic.org]];
{{ :devices:meshtastic:firmware:web_flasher.jpg?600 |flasher.meshtastic.org}}
  - В разделе "**Устройство**" выберите из списка модель своего устройства на базе чипа ESP.
  - В разделе "**Выберите прошивку**" выберите одну из последних сборок релиза "**Alpha**", если хотите получить доступ к последним функциям, или оставьте выбор "**Релиз**" (предложена по умолчанию), чтобы установить последнюю **стабильную** версию.
  - Нажмите кнопку "**Прошить**".
  - В появившемся окне с перечнем изменений в прошивке нажимаем кнопку "**Далее**"
  - В появившемся окне выберите опцию "**Полное удаление и установка**", чтобы полностью очистить память и установить прошивку.
{{ :devices:meshtastic:firmware:flash_device.jpg?600 |выберите опцию "Полное удаление и установка"}}
  - Нажимаем кнопку "**Удалить flash и установить**" для заливки прошивки на устройство.
  - Браузер запросит разрешение на доступ к последовательному порту. Выберите COM-порт, соответствующий вашему модулю (его можно определить через Диспетчер устройств Windows). Ранее вы записывали номер com-порта после подключения Meshtastic устройства, его сейчас и нужно выбрать.
  - Дождитесь завершения процесса. После перезагрузки на экране модуля должно появиться меню Meshtastic.

===== Альтернативные сборки прошивок устройств на mrekin =====

Прошивки на официальном web-флешере не содержат локализации для русского языка. Российское сообщество активно использует локализованные сборки прошивок с ресурса [[https://mrekin.duckdns.org/flasher/|mrekin.duckdns.org]].
Перед ручной установкой прошивки на устройство, необходимо ее скачать на локальный диск.
